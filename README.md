# Penjelasan Singkat Isi Repository
Repositori ini berisi dokumentasi rancangan logika serta kode sumber program C++ untuk menyelesaikan tantangan pemrograman yang terbagi menjadi dua fase:
Fase 1: Dokumen PDF yang memuat pseudocode, flowchart, serta penjelasan logika untuk kedua problem.
Fase 2: File kode sumber berbahasa C++ (`.cpp`) yang mengimplementasikan solusi kedua problem menggunakan *user-defined function* dan library <iostream>.

#  Daftar File
`README.md` : Dokumentasi penjelasan repositori.
`Fase1_Pseudocode_Flowchart` : Dokumen PDF berisi rancangan logika (pseudocode dan flowchart).
`last_astronaut.cpp` : Implementasi program C++ untuk *Problem 1: The Last Astronaut*.
`alien_cipher.cpp` : Implementasi program C++ untuk *Problem 2: Alien-In-The-Middle*.

# Ringkasan Problem
# Problem 1: The Last Astronaut
Program ini mensimulasikan proses seleksi eliminasi astronot dalam formasi melingkar sebanyak N orang dengan aturan perubahan nilai K secara dinamis berdasarkan nomor astronot yang tereliminasi (ganjil atau genap).

# 2. Problem 2: Alien-In-The-Middle
Program ini mengimplementasikan sistem sandi rahasia (*cipher*) berbasis pergeseran posisi alfabet berdasarkan nilai huruf sebelumnya untuk mendeteksi alien yang menyamar di antara para astronot.
